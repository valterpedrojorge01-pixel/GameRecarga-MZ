# GameRecarga MZ

Loja de recargas de jogos para Moçambique.

## Estado do projeto

Este repositório contém a base do projeto. O fluxo de pagamentos deve manter as credenciais da NetShop fora do código-fonte.

## Estrutura inicial

- `README.md` — documentação do projeto.
- `frontend/` — interface da loja (a adicionar).
- `backend/` — serviços de pagamento e pedidos (a adicionar).

## Segurança

Nunca coloque chaves API, tokens ou segredos de pagamento neste repositório. Use variáveis de ambiente ou um gestor de segredos no ambiente de produção.
